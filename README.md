# AKADIVA — Website

Website statis profesional untuk AKADIVA.

## File
- `index.html` — seluruh struktur dan konten website
- `styles.css` — desain, responsive layout, animasi/visual CSS
- `script.js` — menu mobile dan interaksi ringan

## Cara menjalankan
Buka `index.html` di browser.

## Cara online gratis
Website ini cocok untuk GitHub Pages.

1. Buat repository GitHub, misalnya `akadiva-website`.
2. Upload `index.html`, `styles.css`, dan `script.js`.
3. Buka Settings → Pages.
4. Pilih deploy dari branch `main`, folder `/root`.
5. Setelah aktif, GitHub memberi alamat `username.github.io/akadiva-website`.
6. Untuk memakai `akadiva.id`, tambahkan Custom Domain di GitHub Pages lalu atur DNS domain sesuai record yang diberikan GitHub.
