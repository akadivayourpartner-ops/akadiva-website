# AKADIVA — Website

Website statis untuk AKADIVA (Your Academic Partner). Mengikuti AKADIVA Brand Guideline v1.0.

## File
- `index.html` — struktur dan konten
- `styles.css` — desain, warna brand, layout responsif
- `script.js` — menu mobile, penanda menu aktif, formulir ke WhatsApp
- `favicon.svg` — ikon tab browser

## Yang perlu diganti sebelum online
1. Nomor WhatsApp: `WA_NUMBER` di bagian atas `script.js`
2. Email dan lokasi di bagian `#kontak` dan footer pada `index.html`
3. Tautan Instagram / TikTok di footer (ada komentar penanda)

## Memasang di GitHub Pages
Unggah semua file ke root repositori, lalu buka Settings → Pages → pilih branch `main` dan folder `/ (root)`.
